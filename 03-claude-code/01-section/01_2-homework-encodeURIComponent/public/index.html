Why we need encodeURIComponent()

Some characters have a job inside a URL: / separates segments, ? starts the query, & and = split parameters, # starts the fragment, % starts an escape, + means a space in a query.

When a user value (a name, a search, a file name) contains one of them, it changes the meaning of the URL. encodeURIComponent(value) turns those characters into %XX, so the value stays one piece of data.

The app (same data, links built ❌ without and ✅ with encoding)

  • /people – names in a path segment and in a query string
  • /files – uploaded file names in <img src>, links and a download header
